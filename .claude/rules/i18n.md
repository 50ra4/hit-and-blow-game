# 国際化（i18n）規約

- テキストはハードコードしない。必ず翻訳キーを使う。
- 翻訳キーは `src/i18n/locales/ja.json` と `src/i18n/locales/en.json` の**両方**に追加する。
- キーは階層構造（例：`"game.submit"`, `"mode.beginner"`）。

```typescript
// ✅
const { t } = useTranslation();
<button>{t('game.submit')}</button>

// ❌
<button>回答する</button>
```
