# Tailwind CSS コーディング規約

## 基本方針

- Tailwind のユーティリティクラスを優先。カスタム CSS は Tailwind で表現できないもののみ。
- インラインスタイル禁止（Tailwind で表現可能な場合）。

## クラス名の順序

機能別にグループ化: レイアウト → スペーシング → サイズ → 背景・ボーダー → テキスト → エフェクト → トランジション

## レスポンシブ対応

モバイルファースト。`md:` → `lg:` の順でブレークポイントを追加。

## ダークモード対応

`dark:` プレフィックスを使用。

## カスタムクラスの命名規則

- `hab-` プレフィックス + ケバブケース
- 例: `.hab-symbol-flip`, `.hab-tile-glow`

```css
/* ❌ */
.flipAnimation    /* キャメルケース不可 */
.glow             /* プレフィックスなし */
```

## @apply の使用

- 繰り返しの多いパターンのみ使用
- 1箇所でしか使わないスタイルは直接 `className` に記述
